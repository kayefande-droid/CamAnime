Build it yourself

  1. Automatic updates. The app checks this site on launch, downloads the new release and hands it to Android's installer. Library, downloads and watch history are preserved.
  2. Android. Install Flutter, then cd mobile/camanime_app && flutter pub get && flutter build apk --release. The APK lands in build/app/outputs/flutter-apk/app-release.apk.
  3. Windows. Install the .NET 8 SDK, then cd windows/CamAnime.Windows && dotnet publish -c Release -r win-x64 --self-contained.
  4. Point the app at your site URL and sign in with your website account. One shared user database.
