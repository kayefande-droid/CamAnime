Build on your own PC in minutes

  1. Android: install Flutter → cd mobile/camanime_app && flutter pub get && flutter build apk --release → file lands in build/app/outputs/flutter-apk/app-release.apk.
  2. Windows: install .NET 8 SDK → cd windows/CamAnime.Windows && dotnet publish -c Release -r win-x64 --self-contained → CamAnime.exe.
  3. Point the app at your site URL, sign in with your website account — one shared user database.
