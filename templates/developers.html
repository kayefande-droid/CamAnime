Quickstart

curl -s "https://camanime.onrender.com/api/v1/stream/16498/1" \
  -H "x-api-key: ca_live_your_key_here"

The same route exists on the Cloudflare deployment: https://camanjme.camanime.workers.dev/api/v1/stream/16498/1.

Embed it

const res = await fetch("https://camanime.onrender.com/api/v1/stream/16498/1", {
  headers: { "x-api-key": "ca_live_your_key_here" }
});
const data = await res.json();
player.src = data.streams[0].url;   // <video id="player" controls></video>

Keep the key server-side when you can. The proxy URL is Referer-safe, so it plays from your domain without extra headers.
