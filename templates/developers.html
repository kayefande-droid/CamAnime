Quickstart

curl -s "https://camanime.onrender.com/api/v1/stream/16498/1" \
  -H "x-api-key: ca_live_your_key_here"

The same route exists on the Cloudflare deployment: https://camanjme.camanime.workers.dev/api/v1/stream/16498/1.

Embed it

const res = await fetch("https://camanime.onrender.com/api/v1/stream/16498/1", {
  headers: { "x-api-key": "ca_live_your_key_here" }
});
const data = await res.json();
player.src = data.streams[0].url;   // <video id="player" controls></video>

Keep the key server-side when you can. The proxy URL is Referer-safe, so it plays from your domain without extra headers.

Build your own anime site

Three calls are enough for a working site: list the catalogue, show a title with its episodes, then play the episode. Everything is JSON, everything is CORS-open, and the same key works for all of it.

1. Catalogue, filters and search

GET /api/v1/dev/catalog?sort=popular&page=1&perPage=24
GET /api/v1/dev/catalog?q=jujutsu
GET /api/v1/dev/catalog?genre=Action&format=TV&sort=rating
x-api-key: ca_live_your_key_here

{
  "api": "camanime-catalog",
  "results": [
    { "id": "16498", "title": "Attack on Titan", "image": "https://…",
      "episodes": 25, "score": 84, "format": "TV", "year": 2013 }
  ],
  "page": 1, "has_next_page": true,
  "usage": { "calls_today": 1, "daily_limit": 1000 }
}

sort: popular, trending, rating, recent, alphabetical. format: TV, TV_SHORT, MOVIE, OVA, ONA, SPECIAL. genre: any AniList genre name. perPage up to 50.

2. One title and its episodes

GET /api/v1/dev/anime/16498
x-api-key: ca_live_your_key_here

{
  "anime": {
    "id": "16498", "title": "Attack on Titan", "episodes": 25,
    "description": "…", "genres": ["Action", "Drama"],
    "episode_list": [ { "episode": 1, "stream": "https://…/api/v1/stream/16498/1" } ]
  }
}

3. Play it

const key = "ca_live_your_key_here";   // keep this server-side

const list = await fetch("https://camanime.onrender.com/api/v1/dev/catalog?sort=trending", {
  headers: { "x-api-key": key }
}).then(r => r.json());

const ep = await fetch("https://camanime.onrender.com/api/v1/stream/" + list.results[0].id + "/1", {
  headers: { "x-api-key": key }
}).then(r => r.json());

document.querySelector("video").src = ep.streams[0].url;

Send your own users' traffic through your server when you can — the key is the only thing protecting your quota. Links inside streams[] are already absolute and Referer-safe, so the browser plays them from your domain.
